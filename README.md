# ITECH1502-Cybersecurity-Portfolio
My cybersecurity portfolio documenting what I learned about WiFi fundamentals, wireless reconnaissance and hidden networks through TryHackMe

## Project 1: WiFi Fundamentals and Reconnaissance

### Introduction
In this project, I completed the WiFi Fundamentals and Reconnaissance room on TryHackMe. I learned how wireless networks work, how devices communicate and how to identify nearby networks using cybersecurity tools

### Tools Used
I used TryHackMe, Linux Terminal, airodump-ng, iw and wpa_supplicant.

### What I Did
I started by learning about WiFi networks and wireless communication. I used Linux commands to check wireless interfaces and learned how monitor mode works. I then used airodump-ng to scan nearby networks and identify their channels, security types and network names

During the activity, I found a hidden wireless network operating on channel 11. Its network name was not displayed, but the scan showed that the name contained 9 characters. I later identified the network as Staff-Net and connected to it in the lab environment

### What I Learned
This project helped me understand wireless reconnaissance and why hiding a WiFi network name does not provide strong security. I also gained practical experience using Linux commands and investigating wireless network information
